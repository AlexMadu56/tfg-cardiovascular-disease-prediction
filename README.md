# Cardiovascular Disease Prediction: Statistical and Machine Learning Approaches

**Bachelor's Thesis in Statistics | Grade: 9.2/10**

## Overview

This project explores and compares statistical and machine learning classification models for predicting cardiovascular disease using data from the Behavioral Risk Factor Surveillance System (BRFSS 2023).

The study uses more than 428,000 observations and 14 categorical predictor variables related to demographic characteristics, lifestyle and health conditions.

## Models

- Logistic Regression
- Naive Bayes
- Random Forest
- XGBoost

## Methodology

- Data preprocessing and missing value imputation using Random Forest.
- Class imbalance treatment using undersampling, oversampling and SMOTE.
- Training and comparison of classification models.
- Evaluation using ROC-AUC, accuracy, sensitivity, specificity and balanced accuracy.
- Comparison of predictive performance and model interpretability.
